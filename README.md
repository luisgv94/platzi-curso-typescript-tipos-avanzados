## File Descriptions

1. `index.ts`: This file contains the main TypeScript code for the project.
2. `utils.ts`: This file contains utility functions used in the project.
3. `config.json`: This file stores configuration settings for the project.

## Running via CLI

To run the project via the command line interface (CLI), follow these steps:

1. Make sure you have TypeScript installed globally on your system.
2. Open a terminal and navigate to the project directory.
3. Run the following command to compile the TypeScript code into JavaScript:
   `npx ts-node src/app/01-camera.ts` or `ts-node src/app/01-camera.ts`
4. Library used for Faker: https://fakerjs.dev/
